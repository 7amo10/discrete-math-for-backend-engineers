## Welcome to the Discrete Math Lab Index

This curriculum bridges **MIT 6.042J (Mathematics for Computer Science)** directly to production-grade distributed backend systems (Java 21, Spring Framework, Apache Kafka, Apache Cassandra, PostgreSQL InnoDB).

Every weekly module is strictly split into two specialized artifacts:
1. **Editorial Deep-Dive:** The formal discrete mathematics, mathematical models, proofs, and real-world distributed system failure mode postmortems.
2. **Lab Challenge & Verification Suite:** Step-by-step mathematical proofs, architecture walkthroughs, and executable JUnit 5 test suites running in `backend-lab`.
